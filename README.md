# MY-PORTFOLIO

A modern, responsive, and interactive personal portfolio website built using React.js and Vite.
The project is designed to showcase personal profile details, technical skills, projects, achievements, and contact information in a professional and visually appealing manner.

This portfolio demonstrates modern frontend development concepts such as reusable React components, responsive web design, GitHub version control, and live deployment using Vercel.

# 📖 About The Project

The React Portfolio Website was developed to create a professional online presence and showcase frontend development skills. The website provides an interactive and clean user experience while demonstrating modern web development practices.

The portfolio contains multiple sections including:

* Home
* About
* Skills
* Projects
* Contact

The project uses React.js for component-based UI development and Vite for fast build optimization and efficient development workflow. The website is fully responsive and accessible on desktop, tablet, and mobile devices.

# ⚙️ Installation & Setup

## Step 1: Clone Repository

```bash id="o8x2zn"
git clone https://github.com/bhuvishag07/MY-PORTFOLIO.git
```

---

## Step 2: Navigate to Project Folder

```bash id="r7q4lm"
cd MY-PORTFOLIO
```

---

## Step 3: Install Dependencies

```bash id="j1v5ps"
npm install
```

---

## Step 4: Run Development Server

```bash id="l0x8qa"
npm run dev
```

---

## Step 5: Build Project

```bash id="m4c7yn"
npm run build
```

---

# 🌍 Deployment

The project is hosted using Vercel.

Deployment workflow:

1. Source code pushed to GitHub.
2. GitHub repository connected to Vercel.
3. Automatic build and deployment process executed.
4. Live website generated and accessible online.
